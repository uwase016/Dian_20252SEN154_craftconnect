# CraftConnect Rwanda – Data

## Purpose
This folder stores the datasets used in the CraftConnect Rwanda project.

## Planned Data
- Artisan records
- Product records
- Product categories
- Customer records
- Order records
- Payment records
- Stock movement records

## Data Collection
Data will come from verified sources or clearly documented sample records prepared for educational purposes.

## Privacy
No unnecessary personal or confidential information will be included.

## Data Preparation
The data will be organized and prepared for use in the Oracle database.
